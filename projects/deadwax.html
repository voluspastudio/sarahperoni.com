Overview
about what is deadwax
issue 01 / about

A music ezine for artist discovery.

Deadwax is a music ezine and visual culture archive for artist discovery, playlists, and band-driven design. The project turns music coverage into a collectible visual system: digital issues, artist spotlights, playlist notes, posters, stickers, and printed ephemera.

The visual language pulls from indie magazines, Xerox zines, record-store flyers, and dense scrolling web layouts. Designed and copied like something passed around the back of a venue.

02
Digital Ezine
issue 01 scrolling magazine spread
user submitted content

A scrolling magazine spread. Artist features, playlist notes, reviews, and visual references stack across the page in a loose editorial rhythm.

Deadwax is built around user submissions. Readers send in bands and artists they want featured, and each issue collects those submissions into a curated spread of new music.

The layout is intentionally dense, but each section follows a system: feature image, short text, metadata, track reference, and visual tag. Side rails carry issue numbers and category labels so the reader always knows what they are inside.

Artist Features
artist file
new noise / panel system

A cut-and-paste zine system for artist coverage. Image, mark, title, metadata, short note.

Each card works as a quick entry point into an artist's sound and visual world. The treatment is high-contrast and intentionally rough. Duotone or halftone images, photocopy edges, marker scribbles, and small handwritten notes.

This is not a streaming profile. It is a music discovery artifact that feels collected, marked, copied, and passed around.

04
Deliverables
print · digital
copy it / pin it / pass it on

Deadwax extends from the digital ezine into printed pieces, social feeds, and issue merch.

Printed ezine, spotlight cards, social posts, and one piece of issue merch. The deliverables keep the project connected to flyers, record stores, zines, feeds, and bedroom walls. Tactile, slightly imperfect, high-contrast. Never luxury, never polished merch.

04.1 Printed Ezine

The printed issue is the same content, redrawn for paper. A bold flat-color cover with the masthead, then interior spreads that mix artist features, playlist notes, and visual references.

04.2 Social Media

The social media system extends the ezine onto Instagram and other feeds. Posts adapt the artist file format into single-image and carousel layouts so each new feature lands as a recognizable piece of the system.

04.3 T-shirt

One simple piece of issue merch per release. The t-shirt carries the masthead and the issue number, using the same hierarchy as the printed cover. Worn like a back-cover, not a logo drop.

04.4 Cassette Tape

Each issue ships with a limited cassette of the issue's tracklist. The tape carries the same masthead, issue number, and artist file system as the rest of the deliverables. Run small, dubbed at home, traded between readers.

  • Tactile, printed, slightly imperfect. Not luxury merch.
  • Same artist-file logic as the digital ezine
  • Color and metadata stays consistent across surfaces
  • Designed to be folded, taped, or passed along
05
Brand System
visual rules palette · type · grid
visual index / iss 01

Loud color fields, rough image treatment, handwritten marks, dense editorial grids, music-culture metadata.

The system is designed to feel collected and immediate, while still keeping artist features and playlists readable. Sections lean on flat color blocks, photocopy textures, issue numbers, and small tags so the content always feels like part of an issue.

Palette

An indie music zine palette · faded, printed, slightly sun-worn. Washed grass and newsprint cream are the base. Dusty sky and deep olive vary the section panels. Ink black holds the type and photocopy texture. Muted mustard and brick red live only in the annotations, stamps, and issue marks. No pink. No neon. The page reads as record-store flyer, not rave.

Image rules

Images get treated like cutouts, photocopies, or zine panels. Use halftone, duotone, rough masks, repeated thumbnail systems, and sticker-like crops. Skip clean stock photography and influencer imagery.

Layout & marks

Cascading cards, uneven columns, side labels, issue metadata, handwritten arrows. Dense scrolling sections held together by repeated tags and small stamps.

  • Use large flat color fields
  • Treat images like cutouts, photocopies, or zine panels
  • Keep metadata visible
  • Use handwritten marks as accents, not decoration
  • Let layouts feel dense, but keep section logic consistent
  • Use issue numbers and category tags to organize content
  • Mix digital scrolling layouts with print ephemera
